# DSA Practice

My solutions to data structures and algorithms problems, written in Python while preparing for software engineering internships. Each solution is my own, with its time and space complexity and the key idea in one line.

## How I practise

- Solve first without AI or hints, for at least 25 minutes.
- If I get stuck, read an explanation, then rewrite the solution from scratch the next day.
- Write down the complexity and the key idea for every problem.
- Follow the topics in order, from arrays and hash maps to dynamic programming.
